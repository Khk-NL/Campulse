### 集成层级

1. **入口连接**：采用官方稳定网页、指南和获准的小程序入口。暂时失效或依赖会话的门户链接核实后再启用，已有收藏与目录保持。
2. **交互借鉴**：学习其服务分类、常用入口、消息归集和任务直达；结合手机上的课程与项目工作流验证。
3. **授权数据**：学校 SSO、教务数据和待办接口分别申请，获批后读取文档并实现映射。模型 API、开源模块使用和账号认证分开管理。
4. **门户接入**：公开指南要求信息资产备案，通常先完成学校 SSO，由申请单位的校内在职教职工经办；小程序兼容检测决定接入版本。它与 App 自身的微信开放平台资质是两个流程。

找老师时同时提出产品优化建议、微信主体/资质支持的合规路径，以及是否适合通过单位渠道申请门户接入。每种集成明确数据、负责人和维护范围。

### 本轮落实

公共目录补入“随师办入口与指南”，使用官方服务页，便于查看微信小程序和企业微信访问方式。社区入口移出公共目录加载状态，目录缓慢或错误时仍可切换；项目搜索增加 300ms 防抖、提交即搜与清空恢复。部署、测试和 APK 状态见验收记录。

### 本轮设计与边界

- 在校园作品上方提供“校内社区与开源资源”，转到管理员目录并按校园社区标签筛选，沿用搜索、收藏和外部浏览器打开能力。
- 狮学园和 X-lab 以“介绍”命名，来源标注为外部资源，避免把学院报道当成 App 内已托管或实时同步的项目。原平台内容和账号由原平台维护。
- 项目讨论支持全部、讨论中和已解决，服务端查询同时保留项目范围、状态及分页。状态来自实际讨论记录。
- 外校案例用于交互设计参考；本轮公开项目上架范围仍为通过华师大归属核验的项目。真实 API 同步在接口、授权、映射与隐私范围确认后实施。

下一轮优先补充结构化的项目使用方式、参与指引和贡献任务；依据试用反馈确定活动、成员协作与项目状态看板的范围。校内资源接入和学校主体资质支持继续分别推进。
