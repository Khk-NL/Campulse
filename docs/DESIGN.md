# 界面设计

更新：2026-10-21。当前设计以校园代码共享为主线，默认采用暖白、华师大红、柔金黄与蓝紫，支持深色模式和自定义主题。1.6.3 Web 已部署，Android 与 Windows 云包已发布；验证范围见[验收记录](ACCEPTANCE.md)。

## 社区交流（1.6.3，2026-10-21）

在项目探索中增加“社区交流”信息流，汇集已审核华师大公开项目下的讨论。参考 [CSDN 社区](https://community.csdn.net/)与[论坛](https://bbs.csdn.net/)的频道、时间线、来源标识、全文及回复组织，连接每条交流和所属项目。内容由 Campulse 用户发布，帖子归属来源项目。

频道为全部、技术问答（`question`）、经验与建议（`idea`）、项目动态（`update`）、问题反馈（`bug`）。关键词同时查找标题、正文及项目话题，与时间排序、我的 Star 项目筛选共同作用于服务器分页；条件变化回到第一页。信息流可进入完整讨论或返回项目，发帖先选择可见的公开项目，再复用现有 Markdown 编辑预览与提交流程。

社区沿用 `forge_discussions`、`forge_replies` 和已有权限，无新增迁移或依赖。讨论与回复无需预审核；项目进入公开范围仍须逐项审核。当前为开发范围，测试、部署与设备结果统一在[验收记录](ACCEPTANCE.md)登记。

## 1.6.0 产品收拢

本节保留 2026-10-19 的版本设计。

默认首页直接展示项目探索，个人仓库独立成为一级入口。搜索、发布、审核状态、源码链接和项目讨论形成连续路径。游客可以探索项目，登录后管理自己的仓库；探索页保存新草稿后切到个人仓库。

校园辅助集中到一个入口：课程与课表、快速访问、校园广场。约球、组队和扩列保留；课程只呈现时间、教师、教室及相关通知入口。个人页保留账号、仓库、收藏、通知和设置。笔记、AI 与复习工作台退出主流程，历史设计保留在文末。

### GithubStarsManager 的具体借鉴

2026-10-20 已核对其[分类侧栏](https://github.com/AmintaCCCP/GithubStarsManager/blob/main/src/components/CategorySidebar.tsx)、[检索与排序](https://github.com/AmintaCCCP/GithubStarsManager/blob/main/src/utils/repoSearch.ts)及[外部仓库合并](https://github.com/AmintaCCCP/GithubStarsManager/blob/main/src/features/repositories/hooks/useSearchActions.ts)。1.6.1 采用组合查询与稳定分页的思路，Campulse 的条件和排序仍由 PocketBase 执行。

2026-10-21 的 1.6.2 已实现个人分类、颜色及锁定、标签备注与批量整理，个人整理独立于作者公开话题。GitHub 元数据与个人 Stars 采用只读访问，用户逐项导入本人私有草稿；重复导入保留私有状态和已有正文。版本订阅及已读事件独立于 Star 保存。项目分析适配 ChatECNU、DeepSeek 与自部署 EduChat，确认后将建议应用于个人分类和标签；实际连接范围及待补配置见[验收记录](ACCEPTANCE.md)。

## 色彩与标识

默认主色 `#A41F35`，深色变体 `#8F1028`，来源参考华东师范大学[标准色使用规范](https://www.ecnu.edu.cn/wzcd/xxgk/xxbs/bsxz/jcbf/bzssygf.htm)。金黄和蓝紫用于辅助分区与交互状态；大面积内容采用浅底。

用户个性化主色、辅助色通过现有主题设置保存。品牌默认值与用户选择分别处理。学校校标按授权和官方规范使用；应用图标使用 Campulse 自有标识。

色彩与组件主题位于 `apps/mobile/lib/core/theme/`。官网和运营台样式位于 `deploy/pocketbase/pb_public/assets/`。界面优先读取现有主题令牌，错误、选中和完成状态同时使用文字或图形区分。

## 页面结构

- 探索默认展示已审核项目，按全部项目或我的 Star 查找；排序和关键词共同作用于当前视图。
- 社区交流在探索中汇集公开项目讨论，按频道、关键词、时间与我的 Star 项目组合查找，保留项目来源和完整讨论入口。
- 我的仓库整理本人项目、GitHub 绑定和逐项审核进度，保存草稿后可继续编辑并提交审核。
- 校园分为课程与课表、快速访问、校园广场；官方服务标签分类折叠，活动按类型与校区查找。
- 我的集中账号、仓库、收藏、通知与个性化，设置和关于各自收起。
- 官网按首页、功能、社区、关于、下载、隐私等页面组织。
- 运营台采用左侧分层导航、右侧工作区，用户上下文、公共目录与审核队列分别呈现。

社区区分 Campulse 内通过学校归属审核的项目与原平台维护的外部资料。前者提供仓库、讨论、回复和 Star，后者显示来源并链接介绍页。讨论的关键词、类型、状态在项目范围内组合，分页保留当前条件。

高校案例与实际取舍见[路线图](ROADMAP.md#学生项目社区核实与高校参考)：交大 Skill 集市的来源分区、TUNA 的服务与反馈入口、浙大平台的资源联通。界面设计借鉴与源码使用分别登记。

整体工作区采用共享 `WorkspaceBanner`、`WorkspaceAction`、`WorkspaceGrid`、`WorkspaceMetric` 与 `WorkspacePanel`。页头压缩为轻量标题与操作，顶部栏采用浅色，品牌色用于焦点、主操作与状态。统计读取真实记录，网格列数同时受宽度和内容数量约束。红、金和蓝紫随主题变化；悬停、键盘焦点及选中状态分别维护，动效遵循系统减少动画选项。PC 使用侧栏和较宽的项目内容区；手机保持单列滚动。布局阈值和键盘操作见[桌面说明](DESKTOP.md)。

## 交互与动效

宽屏侧栏沿用渐变面板、品牌图标与浮层边框；内容区使用稀疏点阵和淡色背景。项目页以仓库名称、介绍和操作为主，窄屏保持紧凑。卡片高度随字号变化，避免桌面宽卡形成大块留白。Web 启动页先显示品牌与加载阶段，进入后交给共享客户端渲染。

选择栏用色彩和形态表示选中，原图标保持可识别。项目话题用于发起关键词搜索；服务标签仅展示当前内容中实际存在的项。

项目卡片、导航展开和弹窗采用轻量过渡。表单提交显示进度，失败保留输入；项目查询提供加载、结果数与重试状态。横屏或低高度布局压缩固定头部，正文保留滚动空间。

适配窄屏、键盘焦点与系统减少动画偏好。长表格在自身容器横向滚动，页面导航在窄屏收拢。

## 文案

面向用户直接描述状态与下一步操作，如“连接中”“重试”“保存成功”“前往微信”。品牌名统一为 Campulse；学校名称用于实际服务及归属说明。

文案修改优先同步 ARB 与测试。说明文档保留必要的技术限制，功能宣传对应实际可用范围。

## 验证入口

运营台布局与文案检查位于 `scripts/admin-console.test.mjs`、`scripts/ui-copy.test.mjs`；浏览器场景位于 `scripts/admin-console.browser.js`。客户端通过相关 Widget 测试及实际设备检查项目查询、Markdown、输入、提交反馈和重启恢复。结果统一写入[验收记录](ACCEPTANCE.md)。

历史学习布局测试 `test/ui_refinement_test.dart` 保留日期筛选、资料分类与正文搜索、到期卡片入口，以及 320 宽度/1.6 倍字号/深浅主题的回归。设置 `CAPTURE_UI=true` 可生成忽略目录中的布局预览；预览字体通过 `CAMPULSE_UI_FONT`、`CAMPULSE_UI_ICON_FONT` 指向本机字体，仅用于人工检查，发布包沿用实际平台字体。

## 1.4.0 交互与视觉细节

本节保留 2026-10-18 学习工作台仍在主流程时的设计，1.6.0 起对应页面归入存量实现。当前产品入口以前文为准。

连续复习按进入时的到期卡片生成单轮队列，逐张显示答案并保存评分，成功后进入下一张。保存失败保留当前答案，支持重试；提交期间锁定评分和返回，避免重复写入。本轮结果按实际保存数统计。新排程产生的到期卡片在后续轮次读取。电脑可用空格显示答案，数字 1–4 评分。

资料库沿用同一份搜索与分类结果切换列表/卡片视图，卡片列数随宽度及资料数变化，按行懒加载。复制文字、制卡、删除共用原有数据操作，PDF 仍使用受保护附件链路。社区“仅看召集中”在服务端查询过滤，同时覆盖“我报名的”关系分页。

首页、课程、广场和复习页采用淡色光晕与轨道几何，红、金、蓝紫随用户主题变化。卡片切换使用淡入与轻缩放，桌面操作入口悬停轻抬升；系统减少动画开启时使用即时切换。背景几何静态绘制，页面空闲时保持静止。
