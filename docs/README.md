## 维护方式

同一主题维护一份固定名称的文档。实施前读相关代码，实施后更新功能范围、部署依赖和验收结果。测试数量只记录在验收文档，附执行日期；运行版本从 Release 元数据读取。

已合并的临时方案、日期清单、研究笔记和过期阶段日志已从当前目录删除。历史正文可从 Git 历史查阅；整理前的本机文档另有 Git 忽略目录中的备份。第三方源码的来源说明和许可随代码保留。
