# 运营台

更新：2026-10-16。运营台通过当前站点的 PocketBase API 管理数据，登录身份为 PocketBase 超级管理员。入口由运营人员自行收藏，公开官网导航提供产品页面。

管理员、普通 App 用户、Linux SSH 与云厂商账号分别管理。超级管理员可查看和修改全库记录，操作前确认用户、课程和项目上下文；用户数据处理按隐私告知与实际管理职责执行。

## 导航与数据归属

左侧分层导航，右侧为表格或记录表单。桌面侧边栏可收起，窄屏展开后独立滚动；支持搜索、分页、面包屑及状态徽标。

```text
用户工作区
 ├─ 学习 → 课程 / 课程表 / 笔记 / 卡片 / 成果 / 计划与工作台
 ├─ 校园 GitHub
 │   ├─ 个人仓库 → 收到的讨论与回复
 │   └─ 社区项目 → 参与的讨论与回复、Star
 ├─ 校园广场 → 个人召集 / 活动报名 / 收到的报名 / 活动讨论 / 兴趣名片
 └─ 收藏

公共快速访问 → 官方小程序 / 官网
公共内容与审核 → 公告 / 活动 / 项目上架审核 / 校园广场内容
高级数据库 → 集合与记录 / 结构与权限
```

进入用户列表，选择账号并打开工作区；沿课程或项目关系继续筛选。公共目录独立维护，个人收藏引用目录记录。详细映射见[数据模型](DATA_MODEL.md)。

## 查看手机保存的数据

校园广场的四类记录各有表单和操作名称。个人视图要求先选择用户；公共内容区提供全站召集管理。管理员可通过记录编辑将召集结束、调整内容或处理删除；关联报名和讨论遵循数据库级联规则。兴趣名片通过 published 控制公开范围。

1. 手机普通账号保存课程、笔记、计划或复习评分。
2. 运营台选择该账号，进入对应课程或学习分区并刷新。
3. 核对记录 ID、owner、courseId、正文/排程及更新时间。
4. 换另一普通账号检查访问隔离，重启 App 确认读回。

当前展示已保存的记录。实时在线状态、最后活跃、分级运营和操作审计在后续计划中。

## 新增网站或微信小程序

在公共快速访问选择对应分区，填写名称、学校、来源、分类、标签与发布状态。小程序 launchTarget 使用 `wechat-mini-program`、gh_ 原始 ID 和可选页面 path；网站使用 `web` 与真实 HTTPS URL。

微信移动应用 AppID 属于客户端配置；小程序 AppID 可留作公开元数据，实际 OpenSDK 跳转用原始 ID。参数示例位于 `deploy/catalog/ecnu-quick-access.json`。公开读取、手机显示与目的地打开分别检查。

需要批量维护时，`scripts/import-quick-access.mjs` 默认只读预览；显式 `--apply` 写入前保存原服务记录，并尽量保留已有 ID 和收藏关系。

只维护单项时传入 `--name=随师办入口与指南`，先预览，再加 `--apply`；其余目录记录保持原样。该条目是官方访问说明页，实际门户直达地址另行核实。

狮学园、X-lab 的“介绍”条目位于公共目录 Web 分组，带“校园社区”标签及外部来源标识。保持其名称、来源与目标含义一致；取得真实运行入口后再按核实结果更新。它们与作者提交审核的 forge 项目分别管理。

## 校园项目审核

在项目上架审核队列查看作者、README、GitHub、华师大归属材料及状态。核验后通过上架，或填写意见退回修改。作者编辑后重新提交。讨论与回复直接交流，继承项目权限；具体规则见[项目审核](PROJECT_REVIEW.md)。

旧目录作品与新的社区项目分别存放。项目社区使用 forge_repositories，公共服务使用 campus_content；根据实际集合选择操作。

## 高级记录维护

表单从集合元数据读取字段，支持类型化输入、JSON 折叠编辑和文件上传。正文、报名留言与个人介绍使用多行编辑，保存时保留换行。列表支持搜索、分页、查看、新增、编辑与删除；结构、索引和权限由 PocketBase 原后台维护。

永久删除要求核对目标记录 ID 与级联影响；先确认恢复点。超级管理员令牌和密码保存在受控位置。入口地址的发现性与访问认证分别处理。

## 部署与验证

静态文件位于 `deploy/pocketbase/pb_public/`，用 `deploy/update-public-site.sh SOURCE_COMMIT` 按固定完整提交增量发布。部署备份同名页面，数据库与 AI 配置保持独立。

契约测试见 `scripts/admin-console.test.mjs`；浏览器测试见 `scripts/admin-console.browser.js`，其中显式测试响应验证布局交互。真实数据验收用 `scripts/admin-console-acceptance.mjs` 和社区脚本，结果见[验收记录](ACCEPTANCE.md)。
