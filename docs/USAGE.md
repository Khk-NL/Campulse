# 使用指南

更新：2026-10-15。[下载 Android 预览版](https://github.com/Khk-NL/Campulse/releases/tag/campulse-preview)，核对下载页的源码提交与校验信息后安装。

## 账号与同步

在“我的”中注册普通账号，查收验证邮件后登录。密码重置使用注册邮箱。邮件发送、最终收件和链接操作分别验证；当前待验收事项见[验收记录](ACCEPTANCE.md)。

登录后的个人课程、笔记、计划、卡片、成果及收藏写入远程服务。断网时查看页面连接提示并重试；恢复网络后再次读取确认。主题色、语言等设备偏好与云端业务记录分别保存。

## 首页与计划

从首页“我的计划”新增任务，填写标题，并按需要设置截止日期、优先级、标签、子任务和预计用时。点击任务左侧圆圈完成，任务移入已完成页；恢复操作将其放回待办。点击标题编辑，学习记录入口用于记录执行过程。

搜索、排序和标签筛选用于整理当前分组。保存失败时界面回滚并保留可见提示。多台设备同时编辑工作台仍需留意后写覆盖，逐条冲突合并在后续计划中。

## 课程与笔记

“课程”按课程列表和课程表切换。CSV 导入前核对教学周、节次与学校配置，预览导入结果后保存。点击课程进入学习空间。

笔记支持文本与 Markdown 导入，PDF 可作为受保护附件保存。Markdown 上限 2 MB，PDF 上限 20 MB。原文搜索、AI 问答、测验、闪卡与导图的步骤见[课程知识工作台](COURSE_NOTEBOOK.md)。

## 应用

快速访问聚合学校网站、小程序和工具入口。目录由管理员维护，用户可以搜索、按分类筛选和收藏。网站由原服务处理登录。微信小程序受开放平台账号资质及目标访问条件影响，当前状态见[微信配置](WECHAT_APPLICATION.md)。

“随师办入口与指南”打开学校官方访问说明，可查看微信小程序及企业微信的进入方式。校园作品与公共目录独立加载；项目搜索输入后自动查询，也可按键盘搜索键立即查询，清空恢复列表。

校园作品上方的“校内社区与开源资源”打开公共目录中的相关介绍，可查看狮学园与 X-lab 的公开资料。项目详情的讨论与问题支持全部、讨论中和已解决筛选。外部资源的账号与内容在原平台管理。

校园作品用于发现项目和参与交流。在“我的仓库”创建项目、填写 README 并绑定 GitHub；保存后逐项目提交审核。获准公开的项目可进入搜索与探索，其他同学可以关注、提问题、回复及查看处理进展。流程见[项目审核](PROJECT_REVIEW.md)。

## 校园广场

1. 登录并完成邮箱验证，在“应用 → 校园广场”选择活动与组队。
2. 按竞赛、运动、学习、扩列筛选，可再选择校区或搜索技能/话题。
3. 点“发布召集”，填写标题、分工或活动说明、地点；活动时间可选。
4. 其他同学打开召集，点“我想参加”给发起人留言，也可在活动讨论中提问。报名者可以退出。
5. 发起人在详情中查看报名意向、修改安排，结束或重新开放召集。“我发布的”“我报名的”分别查看自己的记录。
6. 在“兴趣名片”编辑昵称、介绍和兴趣技能，打开展示开关后供已验证邮箱的用户查看，随时可以收回。

活动报名是参加意向，具体安排由参加者共同确认。项目审核与活动召集分开；现有校园作品继续逐项提交学校归属材料。

## 我的与个性化

个人工作区可直达学习、计划归档、个人仓库、收藏和校园圈。顶部云刷新用于从服务器重新读取内容，电脑与手机同账号操作见[桌面与同步](DESKTOP.md)。

“我的”集中账号资料与个人设置；设置和关于按分区收起。主题支持明暗模式与自定义主色/辅助色，语言随现有中英配置切换。昵称与头像样式按账号区分，保存在当前设备的偏好存储；跨设备个人资料同步仍在扩展清单。
