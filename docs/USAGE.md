# 使用指南

更新：2026-10-21。本指南按“探索 / 我的仓库 / 校园 / 我的”组织。安装包与线上版本见[验收记录](ACCEPTANCE.md)。[浏览器工作台](https://campus.allezafrique.cn/app/) · [下载 Android 预览版](https://github.com/Khk-NL/Campulse/releases/tag/campulse-preview)。

## 账号与同步

在“我的”中注册普通账号，查收验证邮件后登录。密码重置使用注册邮箱。邮件发送、最终收件和链接操作分别验证；当前待验收事项见[验收记录](ACCEPTANCE.md)。

登录后的个人项目、讨论、关注、课程及收藏写入远程服务。断网时查看页面连接提示并重试；恢复网络后再次读取确认。主题色、语言等设备偏好与云端业务记录分别保存。

## 探索校园项目

打开 Campulse 默认进入“探索”。搜索项目名称、用途或技术话题，查看已通过华师大归属审核的项目。

项目详情集中 README、GitHub 源码链接、关注和 Issue 式讨论。问题支持全部、讨论中、已解决筛选，打开问题后可以回复并查看处理进展。讨论与回复使用项目自身的访问范围。

## 管理自己的仓库

1. 进入“我的仓库”，创建项目或绑定已有 GitHub 仓库。
2. 补充项目介绍、README、技术话题和使用入口。
3. 在对应项目中提交华师大归属材料，查看该项目的审核状态与处理意见。
4. 审核通过后，项目出现在探索与公开搜索中，同学可以关注和参与讨论。

“我的仓库”整理本人全部项目；公开探索展示已获准上架的项目。每个项目单独提交、单独处理，具体流程见[项目审核](PROJECT_REVIEW.md)。Campulse 的讨论和关注保存在自身服务中，GitHub 源码链接打开对应外部仓库。

## 收藏、订阅与 AI 分析

在探索、个人仓库或“我的”打开“收藏与订阅”。我的 Star 支持个人分类、颜色、标签、备注、关键词搜索、排序和批量移动；分类锁定后，应用 AI 建议时保留原分类。项目详情的“整理与 AI 分析”可直接打开当前项目。

版本订阅独立于 Star，关联 GitHub Release。主动检查后，消息写入本人的版本时间线，可标记已读和查看原版说明。填写个人 GitHub Token 后，可分页查看自己的 GitHub Stars，逐项导入 Campulse 私有草稿，再按项目申请公开审核。

“我的 → 设置 → GitHub 与 AI 设置”可选择 ChatECNU、DeepSeek 或管理员部署的 EduChat。保存前可实际测试连接，分析结果包含摘要、用途、上手步骤和分类标签建议。Key 配置、模型选择及完整步骤见[集成指南](FORGE_INTEGRATIONS.md)。

## 校园辅助

“校园”分为“课程与课表 / 快速访问 / 校园广场”。

### 课程与课表

在课程列表和课程表之间切换。CSV 导入前核对教学周、节次与学校配置，预览导入结果后保存。点击课程查看教师、教室和上课安排。通知入口读取远程公告及个人消息。

笔记、PDF、AI 学习和复习卡片已从本轮客户端主流程撤下，相关历史实现见[课程知识工作台](COURSE_NOTEBOOK.md)。

### 快速访问

快速访问聚合学校网站、小程序和工具入口。公共目录由管理员维护，用户可以搜索、按分类筛选和收藏。网站由原服务处理登录。微信小程序受开放平台账号资质及目标访问条件影响，当前状态见[微信配置](WECHAT_APPLICATION.md)。

“随师办入口与指南”打开学校官方访问说明，可查看微信小程序及企业微信的进入方式。“校内社区与开源资源”收录相关公开介绍，外部资源的账号和内容在原平台管理。

### 校园广场

1. 登录并完成邮箱验证，在“校园 → 校园广场”选择活动与组队。
2. 按竞赛、运动、学习、扩列筛选，可再选择校区、打开“仅看召集中”或搜索技能/话题。“我报名的”同样支持召集状态筛选。
3. 点“发布召集”，填写标题、分工或活动说明、地点；活动时间可选。
4. 其他同学打开召集，点“我想参加”给发起人留言，也可在活动讨论中提问。报名者可以退出。
5. 发起人在详情中查看报名意向、修改安排，结束或重新开放召集。“我发布的”“我报名的”分别查看自己的记录。
6. 在“兴趣名片”编辑昵称、介绍和兴趣技能，打开展示开关后供已验证邮箱的用户查看，随时可以收回。

活动报名是参加意向，具体安排由参加者共同确认。项目审核与活动召集分开；现有校园作品继续逐项提交学校归属材料。

## 我的与个性化

“我的”集中账号、个人项目、收藏、通知和设置。云刷新用于从服务器重新读取内容，电脑与手机同账号操作见[桌面与同步](DESKTOP.md)。

设置和关于按分区收起。主题支持明暗模式与自定义主色/辅助色，语言随现有中英配置切换。昵称与头像样式按账号区分，保存在当前设备的偏好存储；跨设备个人资料同步仍在扩展清单。
