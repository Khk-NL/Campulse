好用的校园工具，
值得有一个交流的地方。

Campulse 是校园项目共享社区。发现作品、认识作者，再围绕具体项目讨论需求和问题。社区互动属于 Campulse，源码通过项目绑定的 GitHub 链接访问。

FOR BUILDERS

整理自己的仓库

创建项目并填写介绍、使用入口与 GitHub 链接。个人仓库展示自己的各个项目，也记录每一项的审核状态。

FOR CAMPUS

逐项目提交审核

每个项目独立申请华师大归属核验与上架审核，通过后进入校园作品、搜索和探索。

FOR EVERYONE

在项目中交流

Star 感兴趣的作品，发起 Issue 式讨论并回复。讨论与回复直接参与，反馈可以留在对应项目。

MEET ON CAMPUS

写代码，也找伙伴。

校园广场保留竞赛组队、约球和扩列。项目交流围绕作品展开，日常召集在广场继续。
