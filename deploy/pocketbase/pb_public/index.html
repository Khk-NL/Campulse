WHY CAMPULSE

你的项目，
也许正好帮到同校的人。

选课脚本、课程设计、开源工具。写完之后，把项目带到同学面前，听听他们怎么用、遇到了什么问题。

Campulse 把学生项目放在首页。个人仓库整理自己的作品，每个项目独立提交华师大归属核验与上架审核，通过后进入校园探索和搜索。

CAMPUS GITHUB

校园的 GitHub，
从一个项目开始。

在 Campulse 关注项目、发起 Issue 式讨论和回复，通过项目的 GitHub 链接阅读源码、参与代码协作。Star 和讨论保存在 Campulse 社区。
