A SMALL TEAM, A CLEAR FOCUS

把校园代码共享，
做得更顺手。

Campulse 是面向华东师范大学的独立校园项目社区，现阶段以预览版持续开发。

OUR STARTING POINT

从找入口，
到找同学的作品。

项目最初从聚合校园小程序和网站出发。做着做着，我们更想解决的是：同学写出的工具，怎样被同校的人找到，又怎样获得具体反馈。

现在把项目探索、个人仓库与讨论放到中心。课表、课程通知和官方快速访问保留为辅助功能，校园广场继续承接组队和日常交流。

视觉参考华东师范大学配色规范，产品使用 Campulse 自有标志，由项目开发者独立运营。

PRODUCT FOCUS

围绕一次真实的项目交流。

创作

先整理自己的项目

在个人仓库填写介绍和使用入口，关联 GitHub 源码链接，再为需要公开的项目独立提交审核。

发现

让校园作品被找到

通过华师大归属核验与上架审核的项目进入校园作品、搜索和探索，供同学浏览、Star 和使用。

交流

把反馈留在项目里

Issue 式讨论和回复记录问题、建议与处理进展。源码阅读与代码贡献沿着项目的 GitHub 链接继续。
