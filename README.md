# Campulse

学习、服务、创新。

Campulse 是面向高校学生的校园应用，首站适配华东师范大学。你可以在这里整理课程和笔记、找到常用校园服务，也可以发布自己的项目，与同学围绕作品交流。

学校的随师办承担官方服务门户，ChatECNU 与 EduWork 提供学校 AI 能力。Campulse 继续聚合这些入口，结合移动端课程整理、个人复习和学生项目交流。学校服务与 Campulse 自有数据按各自账号和授权范围连接。[功能对比与集成路线](docs/ROADMAP.md#学校平台对比与集成)

## 学习，从一门课开始

课程列表和课程表是学习的入口。进入一门课，可以集中查看笔记、资料、任务和复习内容。

- 通过 CSV 导入课程表，按教学周查看上课时间、教师和教室。
- 导入 PDF 电子课本与 Markdown 笔记，在课程内阅读、整理和检索。
- 按 PDF 与文字分类查找资料，搜索笔记标题和正文；支持列表/卡片、标题排序与复制文字，电脑端并排查看资料、提问与成果。
- 围绕课程资料向 AI 提问，查看回答中的原文证据，生成测验、闪卡和思维导图。
- 按到期顺序连续复习卡片，逐张回想、评分与保存，由服务端 FSRS 调度下一次复习。
- 记录待办与学习计划，按今天、未来七天或逾期筛选；完成后归档，回看已完成事项。

登录后，个人课程、笔记、计划、复习卡片和学习成果通过远程服务保存。课程资料与学习记录按账号组织，设备端保留登录会话。

## 常用校园服务，放在一起

教务、图书馆、学校官网和校园小程序都可以进入快速访问。按分类查找、搜索或收藏，减少反复寻找入口的时间。

公共服务目录由管理员维护，个人收藏随账号保存。目前已录入华师大官网、图书馆、本科生院，以及校友服务大厅、体育场馆管理等小程序入口。

网页入口已完成 App 点击跳转测试。小程序使用微信 OpenSDK，直接拉起仍需完成开放平台账号资质条件及设备验收，详见下方预览版状态。

## 校园 GitHub：发现项目，也参与项目

校园里有同学做工具、写程序，也有同学遇到问题、提出想法。Campulse 把这些交流放在项目旁边。

在“我的仓库”中创建项目，写介绍和 README，添加话题，也可以绑定已有的 GitHub 仓库。每个项目独立提交审核，并显示审核进度和处理意见。

管理员核验华师大归属并批准上架后，项目进入校园作品、搜索和探索。其他同学可以关注项目、提出问题或建议、回复讨论；问题支持解决和重新开启。讨论与回复继承项目的访问权限，直接交流。

Campulse 的项目、讨论、回复和关注记录保存在自己的数据库中。GitHub 链接用于连接外部源码仓库，社区内容由 Campulse 独立维护。

项目列表按仓库组织介绍、技术话题和审核状态。点击话题继续查找相关作品，也可以直接打开项目绑定的 GitHub 源码。

校内已有狮学园等学生作品项目及 X-lab 开源社区。Campulse 提供“校内社区与开源资源”入口，连接经核实的介绍页，并继续完善自己的项目审核、问题处理与移动使用流程。外部项目的当前运营、账号和接口按各平台实际情况核实，相关对比见[集成路线](docs/ROADMAP.md#学生项目社区核实与高校参考)。

下一轮社区迭代将优先完善已上架项目加入个人快速入口、消息通知和协作体验。

## 校园广场：组队、约球与兴趣交流

在“应用 → 校园广场”发布竞赛组队、运动约局、学习搭子或扩列召集，按校区和类型查找。活动里可以报名、退出和讨论；发起人可修改安排、结束或重新开放召集。“我发布的”和“我报名的”分别整理自己的记录。

兴趣名片由本人选择公开，介绍自己的兴趣、技能和所在校区。报名留言由发起人和报名者查看，活动讨论供已验证邮箱的用户交流。校园项目继续采用逐项目归属审核；活动召集与项目上架分别管理。

## 手机与电脑接着用

Web、Windows 与 Android 共用 Flutter 业务代码和 PocketBase 账号。电脑采用侧栏导航，课程学习空间可并排查看资料、提问和工作台；窄窗口切回紧凑布局。课程置顶、入口收藏随账号保存，云端内容可从各端刷新读回。

[浏览器工作台](https://campus.allezafrique.cn/app/)用于直接体验，使用自己的普通账号登录。[Web 开发与发布](docs/WEB.md)提供本机预览、热重载和云构建步骤；Windows 继续作为独立客户端提供。

Windows 安装与跨端验收见[桌面与同步](docs/DESKTOP.md)。下载和发布状态以对应 Release 与[验收记录](docs/ACCEPTANCE.md)为准。

## 面向华师大，也给后续适配留出空间

首期视觉参考华东师范大学[标准色使用规范](https://www.ecnu.edu.cn/wzcd/xxgk/xxbs/bsxz/jcbf/bzssygf.htm)，界面支持主题色个性化。学校服务优先连接已有的官方入口。

校方身份认证与数据接口以[华东师范大学开发者平台](https://developer.ecnu.edu.cn/)为后续对接依据，通过高校适配层处理学校之间的差异。当前账号体系由 Campulse 的 PocketBase 服务提供，校方统一认证接入列入后续计划。
