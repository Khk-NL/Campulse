# Campulse

校园代码，和一起做项目的人。

Campulse 是面向高校学生的代码与项目共享平台，首站适配华东师范大学。在这里发布自己的工具，发现同学的作品，围绕项目提问题、交流想法，找到一起维护和开发的人。

1.6.0 的产品调整将项目社区放到第一入口，课程表、校园通知和常用服务作为辅助。约球、竞赛组队与扩列继续保留在校园广场。笔记、PDF 和 AI 学习工作台退出本轮客户端主流程，开发精力集中到项目发布、发现和交流。

## 校园 GitHub：打开就能发现项目

校园里有同学做工具、写程序，也有同学遇到问题、提出想法。Campulse 把这些交流放在项目旁边。

“探索”是默认首页，集中展示已审核的校园项目。搜索名称、用途和技术话题，打开项目查看 README、源码入口与讨论，关注感兴趣的作品。

在“我的仓库”中创建项目，写介绍和 README，添加话题，也可以绑定已有的 GitHub 仓库。个人仓库整理自己的全部项目，每个项目独立提交审核，并显示审核进度和处理意见。

管理员核验华师大归属并批准上架后，项目进入公开探索与搜索。其他同学可以关注项目、提出问题或建议、回复讨论；问题支持解决和重新开启。讨论与回复继承项目的访问权限，直接交流。

Campulse 的项目、讨论、回复和关注记录保存在自己的数据库中。GitHub 链接用于连接外部源码仓库，社区内容由 Campulse 独立维护。

下一步围绕项目使用说明、贡献任务、讨论通知和协作体验继续打磨。校内已有社区与开源资源的比较见[集成路线](docs/ROADMAP.md#学生项目社区核实与高校参考)。

## 校园：课表、通知和常用入口

课程列表与课程表保留 CSV 导入、教学周和节次安排，点击课程查看时间、教师与教室。校园通知从远程服务读取，公共快速访问聚合教务、图书馆、学校官网和校园小程序。

公共目录由管理员维护，个人收藏随账号保存。学校网站使用原服务的登录流程，小程序跳转状态按微信开放平台资质和实际设备验收记录说明。

## 校园广场：组队、约球与兴趣交流

在“校园 → 校园广场”发布竞赛组队、运动约局、学习搭子或扩列召集，按校区和类型查找。活动里可以报名、退出和讨论；发起人可修改安排、结束或重新开放召集。“我发布的”和“我报名的”分别整理自己的记录。

兴趣名片由本人选择公开，介绍自己的兴趣、技能和所在校区。报名留言由发起人和报名者查看，活动讨论供已验证邮箱的用户交流。校园项目继续采用逐项目归属审核；活动召集与项目上架分别管理。

## 手机与电脑接着用

Web、Windows 与 Android 共用 Flutter 业务代码和 PocketBase 账号。主导航统一为“探索 / 我的仓库 / 校园 / 我的”；电脑使用侧栏，手机使用底部导航。项目、讨论、课程与收藏从远程服务读取。

[浏览器工作台](https://campus.allezafrique.cn/app/)用于直接体验，使用自己的普通账号登录。[Web 开发与发布](docs/WEB.md)提供本机预览、热重载和云构建步骤；Windows 继续作为独立客户端提供。

Windows 安装与跨端验收见[桌面与同步](docs/DESKTOP.md)。下载和发布状态以对应 Release 与[验收记录](docs/ACCEPTANCE.md)为准。

## 面向华师大，也给后续适配留出空间

首期视觉参考华东师范大学[标准色使用规范](https://www.ecnu.edu.cn/wzcd/xxgk/xxbs/bsxz/jcbf/bzssygf.htm)，界面支持主题色个性化。学校服务优先连接已有的官方入口。

校方身份认证与数据接口以[华东师范大学开发者平台](https://developer.ecnu.edu.cn/)为后续对接依据，通过高校适配层处理学校之间的差异。当前账号体系由 Campulse 的 PocketBase 服务提供，校方统一认证接入列入后续计划。

## 当前范围与预览版状态

项目处于 MVP 开发与小范围验收阶段。以上按 1.6.0 的产品范围组织，安装包、线上页面与源码可能处于不同发布阶段；实际版本及操作证据见[验收记录](docs/ACCEPTANCE.md)。Android、Windows 与 Web 由 GitHub Actions 构建，下载页提供对应源码提交与校验信息。

| 部分 | 当前进展 |
| --- | --- |
| 项目社区 | 已有个人仓库、GitHub 绑定、逐项目审核、项目讨论、回复和关注；1.6.0 将探索与个人仓库提升为一级入口 |
| 校园辅助 | 保留课程列表、课表导入、基础详情、通知、快速访问和校园广场 |
| 旧学习模块 | 笔记、PDF、AI 学习、复习卡片从客户端主流程撤下，后端与历史实现作为存量模块管理 |
| 微信小程序 | 四个入口已完成显示与实际点击测试，微信返回 `has_no_permission`；客服确认当前个人未认证账号受跳转范围限制，待资质条件满足后复测 |
| 发布前检查 | 正式域名恢复、邮件验证与密码重置收件、微信真机跳转列入后续验收 |

接口检查、浏览器操作和实际设备点击分别记录。历史学习功能的测试与部署记录保留原日期，供追溯实现。

## 一起完善 Campulse

试用时，可以通过 [Issues](https://github.com/Khk-NL/Campulse/issues)反馈使用问题或功能建议。反馈请附 App 版本、操作步骤、预期结果和实际表现；截图注意遮挡个人信息。

欢迎参与项目发现、仓库展示、讨论协作和校园服务整理。提交前先阅读对应模块的实现与验收记录，让改动保持小而完整。
